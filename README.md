# Nell info

Public pages for the Nell app (App Store support and privacy URLs), served by GitHub Pages:
- `index.html`: support page (help and contact): https://lpcote4.github.io/nell-info/
- `privacy/index.html`: privacy policy: https://lpcote4.github.io/nell-info/privacy/

Pages: Settings > Pages > Deploy from a branch, `main`, `/ (root)`. The policy is also in the app repo
(`AppStore/privacy-policy.html`): change both together.
